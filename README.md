# All Photos

An offline gallery for Pixel, built with Material 3 Expressive.

- Every photo and video on the phone (HEIC, MOV, RAW, HDR), no cloud, no ads, no internet permission
- Screenshots tab: grouped by app and website, auto-trash after 30 days unless marked important
- "Mark as important" notification after each screenshot (screenshots within 30 seconds share one)
- On-device search of text and things in photos
- Cleanup: similar photos, large files, WhatsApp/Telegram media after 30 days, 30-day trash
- Video player with exact frame capture, frame stepping, speed, trim
- Two-level details (key facts, then "Show more")
- HEIC to JPG, light photo editing (crop, adjust, filters) saved as a copy or over the original

GitHub Actions builds the APK on every push and runs it on an emulator. The latest APK is on the `builds` branch.
